# مؤسسة الإتقان — Etqan Doors & Windows (نسخة تسليم نهائية)

موقع تعريفي ثابت (Single-page) عربي RTL، يعمل بـ **HTML/CSS/JS** بدون تبعيات تشغيل خارجية (خطوط وGSAP/ScrollTrigger محلية داخل المشروع).

## التشغيل محلياً
يفضّل تشغيل خادم ثابت (لضمان تحميل الخطوط/الملفات بشكل صحيح):

```bash
cd etqan-final-delivery
python -m http.server 8080
# http://localhost:8080
```

> لا يتطلب المشروع عملية Build؛ هو جاهز كملفات ثابتة.

## النشر
ارفع محتويات المجلد كما هي إلى أي استضافة ثابتة (Cloudflare Pages / Netlify / Nginx / Apache / IIS) مع ضبط المجلد الجذر على هذا المجلد. بعد اعتماد رابط الموقع النهائي، أضف وسم `canonical` المعتمد في `index.html`.

## البنية
- `index.html` — الصفحة الكاملة
- `css/` — `fonts.css` (خطوط محلية)، `styles.css`, `motion.css`
- `js/` — `main.js` (سلوك/قائمة/نموذج/إعداد التواصل)، `motion.js` (حركات GSAP)
- `assets/fonts/` — Cairo + Tajawal (WOFF2، محلية)
- `assets/vendor/` — `gsap.min.js` + `ScrollTrigger.min.js` (محلية)
- `public/` — الشعار، الأيقونات، صور المنتجات/المشاريع/البطاقات
- `ASSET-ATTRIBUTION.md` — توثيق مصادر الصور والرخص
- `DELIVERY-REPORT.md` — ما تم إصلاحه وما يلزم اعتماده

## إعداد التواصل (مهم)
أرقام الهاتف/واتساب **غير مُضافة** (لا توجد أرقام تجريبية/سعودية). عند اعتماد **رقم الجزائر**، حدّث `CONTACT` في `js/main.js`:
- `whatsapp`: أرقام بصيغة دولية بدون `+`
- `tel`: بصيغة `+...`
- `phoneDisplay`: النص الظاهر للرقم

حتى اعتماد الرقم، تبقى روابط التواصل غير فعّالة مع تنبيه واضح (حماية من روابط خاطئة).

## ملاحظات محتوى
- لا يحتوي الموقع على أرقام إحصائيات/شهادات وهمية أو غير معتمدة.
- نصوص الخدمات (التركيب/التوريد/التسليم/الزيارات) صيغت بشكل حذر دون وعود غير مؤكدة؛ راجعها واعتمدها وفق خدمات المؤسسة الفعلية.
- رابط `canonical` النهائي غير مضاف (ولا يُستخدم `example.com`) — يُضاف بعد اعتماد عنوان الموقع.
- بيانات العنوان وساعات العمل وإجابات FAQ النهائية بانتظار اعتماد المؤسسة.
- صورة تصنيف PVC (باب/شباك) موثقة وتحتاج تأكيداً بصرياً من المالك.
